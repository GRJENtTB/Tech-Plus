Linux Command Line Simulator

Practice Mission: Follow the steps to uncover the hidden phrase.
1. pwd
Displays the current directory.
2. ls
Lists files and directories.
3. mkdir JROTC
Creates a new directory named JROTC.
4. cd JROTC
Changes to the JROTC directory.
5. touch drill.txt
Creates a new empty file named drill.txt.
6. cp drill.txt /home/cadet
Copies drill.txt to the home directory.
7. cd /home/cadet
Changes to the home directory.
8. ls
Displays drill.txt to confirm it was copied.
9. mv drill.txt roster.txt
Renames drill.txt to roster.txt.
10. ls
Displays roster.txt to confirm the rename.
11. rm roster.txt
Deletes roster.txt.
12. ls
Confirms roster.txt was removed.
13. cat values.txt
Displays the contents of values.txt.
14. clear
Clears the terminal screen.
